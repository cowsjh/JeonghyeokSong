## x := x/10 (walrus operator)

```python
x = 24;
print(x := x/10);

>>> 2.4



x = 24;
print(x = x/10);

>>> 에러 출력
```

`:=` 오른쪽을 왼쪽에 적용한 결과를 바로 출력할 수 있게 한다.

```python
x = 24;
a = [x := x/10]
print(a)

>>> [2.4]


x = 24;
x := x/10

print(x)

>>> 에러 출력
```

`:=` 문법은 단독으로 사용이 불가능 하고 값을 지정할 때만 쓰일 수 있는거 같다.
