```python
print("%.6f" %0.01)
>> 0.010000

print("%6.f" %1)
>>     1
( 앞에 6칸 뜀 )

print("%10.5f" %1.2)
>>    1.20000
(앞에 10칸 뛰고 뒤에서 5칸 앞으로)

"%앞의 공간.뒤 공간f" 이라고 생각 하면 될듯
```

추가로 houdini 에서 패딩

```python
s@a = sprintf("%*0d",4,57);
->0057
(맨뒤 숫자가 4번째에 있게 0을 앞에 붙임)

s@a = sprintf("%*d",4,57);
->  57
(맨뒤 숫자가 4번째에 있게 앞을 두칸 띄움)

s@a = sprintf("%.*d",6,5.7101345247);
->5.71013
(뒤 6자리 까지 표기)

d를 f 로바꾸면 5.7같은 딱떨어지는 숫자도 000 붙힐 수 있음
```
