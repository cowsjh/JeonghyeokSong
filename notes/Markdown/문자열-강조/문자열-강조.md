### 기본 텍스트 강조 문법

```
인라인 : `텍스트`
볼드 : **텍스트**
이탤릭 : *텍스트*
취소선 : ~~텍스트~~
마크 : <mark>텍스트</mark>
인라인 볼드 : **`텍스트`**
```

### 코드 블록 색상 강조

diff 로 코드블럭을 시작.

```diff
+ 이 줄은 초록색 배경으로 표시됩니다. (성공, 추가)
- 이 줄은 빨간색 배경으로 표시됩니다. (실패, 삭제)
! 이 줄은 주황색 계열로 보일 수 있음 (주의)
```
