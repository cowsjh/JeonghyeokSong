# gitignore 문법

`.gitignore`는 Git이 **추적하지 않을 파일**을 한 줄에 하나씩 패턴으로 적는 파일이다. ([Git Basic](../git-basic/main.md)에서 정리한 add→commit 흐름에서 아예 스테이징 대상에 들어오지 않게 막는 장치.)

## 기본 규칙

| 패턴 | 의미 |
|------|------|
| `# 주석` | `#`으로 시작하면 주석 |
| (빈 줄) | 무시됨. 가독성용 구분자 |
| `file.txt` | 어느 위치든 `file.txt`라는 이름이면 무시 |
| `*.log` | `.log`로 끝나는 모든 파일 |
| `build/` | 끝에 `/` → `build` **디렉토리**만 무시 |
| `/file.txt` | 앞에 `/` → **루트(최상위)** 의 `file.txt`만 무시 |
| `!important.log` | `!` → **예외(무시 취소)** |

## 와일드카드

- `*` — 슬래시(`/`)를 제외한 임의 문자열. 예: `*.tmp`
- `?` — 임의의 한 글자. 예: `file?.txt`
- `[abc]`, `[0-9]` — 대괄호 안 문자 중 하나
- `**` — 디렉토리를 가로지르는 매칭
  - `**/foo` — 어느 깊이의 `foo`든
  - `foo/**` — `foo` 아래 전부
  - `a/**/b` — `a`와 `b` 사이 임의 깊이

## 슬래시 위치가 의미를 바꾼다

```gitignore
doc/       # 어디에 있든 doc 디렉토리
/doc       # 루트의 doc만
```

## 예외(!)의 함정

부모 디렉토리가 통째로 제외되면 그 안의 파일은 `!`로 되살릴 수 없다.

```gitignore
logs/            # logs 폴더 전체 무시
!logs/keep.log   # ← 작동 안 함! 부모가 이미 제외됨

# 이렇게 해야 예외가 산다
logs/*
!logs/keep.log
```

## 핵심 주의점

- **이미 추적 중인 파일은 `.gitignore`에 적어도 무시되지 않는다.** 먼저 `git rm --cached <file>`로 인덱스에서 빼야 한다.
- 패턴은 **위에서 아래로** 평가되고, 뒤 규칙이 앞 규칙을 덮어쓴다(특히 `!`).
- 특수문자는 역슬래시로 이스케이프: `\#foo` → `#foo`라는 이름의 파일.
